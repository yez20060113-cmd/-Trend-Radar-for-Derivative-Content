# 追星二创素材雷达

每天自动扫一遍抖音，回答一个问题：**今天有什么东西可以直接拿来剪视频。**

输出的不是「今天有哪些娱乐新闻」，而是三类可复用资产：

- **BGM** —— 正在被大量使用的歌（不只看榜单）
- **文案** —— 被多条视频复制、且脱离原语境仍成立的句子
- **玩法** —— 有参与入口的挑战 / 可套用的模板

每天 09:00 自动跑一次，产出 Markdown 日报 + 邮件。

---

## 它长什么样

```
## 圈内素材（追星垂直）（8）

| # | 素材 | 类型 | 主体 | 证据 |
|---|---|---|---|---|
| 1 | 我要逮捕你舞蹈挑战 | 挑战 | ILLIT | 圈内；28 条内容在用（含主体 28 条），连续第 5 天（热度上升）｜配乐：You're Under Arrest |
| 2 | 管他的公路尽头     | BGM  | 王源  | 新歌榜 #4；抖音 20 条内容提到该歌名；连续第 2 天（仍在榜） |
| 3 | CallMyName挑战    | 挑战 | NAME女团 | 圈内；19 条内容在用（含主体 19 条）｜配乐：Call My Name |

## 今日可用文案（3 条）

| 文案 | 在用 | 怎么用 | 出处 | 配套素材 |
|---|---|---|---|---|
| 把天看破  | 4 条 | 配粉丝陪偶像扛过风雨、灯海齐亮的画面 | 王源《管他的公路尽头》 | 管他的公路尽头 |
| 画地为牢  | 3 条 | 配多年只追一人、守在原地等待的混剪 | 《后会友期》 | 我要逮捕你舞蹈挑战 |
| 好舞不挑曲 | 3 条 | 配偶像任意音乐下的卡点舞蹈混剪 | — | 霸王龙舞步转场挑战 |
```

「证据」写的是**多少条内容在用**，不是热度值。因为热度高不代表能拿来剪。

---

## 它怎么判断

核心思路：**判定的单位是「素材」，不是「视频」，也不是「事件」**。

```
采集 400 条内容
   ↓  抽实体（歌名 / 模板骨架 / 「XX挑战」）
   ↓  同一素材被多条提到 → 合成一张卡
   ↓  门槛：圈内 ≥2 条在用，跨圈 ≥3 条
   ↓  领域过滤：体育/电竞/时政类丢掉
   ↓  跨天治理：连续 3 天热度不涨就「让位给新素材」
日报：8 张圈内 + 3 张跨圈
```

完整判据在 [`CoreAssets/HotspotCriteria.md`](CoreAssets/HotspotCriteria.md)，
这是唯一的判定准则来源，代码里的阈值都以它为准。

## 快速开始

```bash
git clone <repo> && cd 产品探索

python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # 再填 key，见下一节
cp CoreAssets/keywords.template.md /tmp/kw.md       # 照着建 CoreAssets/keywords.json

python scripts/doctor.py      # 自检：依赖 / 密钥 / 端口 / 词库
python scripts/launch_edge.py # 启动 Edge，然后在窗口里扫码登录抖音
python scripts/collect_douyin.py   # 采集（第一次建议加 --limit 3 试试）
python -m src.main --run           # 判定 + 出日报
```

产物在 `sandbox/runs/<时间戳>/report.md`。

> **不需要** `playwright install`。这里用的是 `connect_over_cdp` 连已有浏览器，
> 不下载浏览器二进制。

## 前置条件

**这不是一个 clone 下来就能跑的工具。** 所有外部服务都要你自己申请，
否则只能跑到一半。

### 一、必须人工完成的（没有就跑不了）

| 项 | 说明 |
|---|---|
| **Windows + Edge** | 采集靠 CDP 连本机 Edge，只在 Windows 上验证过 |
| **抖音账号** | 需要在 Edge 里**人工扫码登录**一次。登录态存在 `.edge-cdp/`，不会上传 |
| **Edge 调试端口** | `python scripts/launch_edge.py` 会自动用 9222 端口启动 |

登录态会过期。如果搜索页能打开但没有结果，大概率是被手机端顶掉了，
重新扫码即可（`douyin.com/user/self` 能打开主页就是好的）。

### 二、需要自己申请的 API

| 环境变量 | 用途 | 从哪拿 | 免费额度 | 不填会怎样 |
|---|---|---|---|---|
| `RADAR_LLM_KEY` | 模型层：素材理解 + 文案评估 | 任意 OpenAI 兼容服务（DeepSeek / OpenAI / 硅基流动…） | 各家不同，本项目实测约 ¥0.2/天 | 自动降级成纯规则版：素材卡少几张，「可用文案」栏不出现 |
| `SANDBASE_API_KEY` | 读视频真实配乐 | https://api.sandbase.ai 注册 | 100 次/天，$0.001/次 | 素材卡没有「配乐」字段 |
| `SMTP_USER` | 发件邮箱 | QQ 邮箱 | 免费 | 只出 Markdown，不发邮件 |
| `SMTP_PASS` | 邮箱**授权码**（16 位，不是登录密码） | mail.qq.com → 设置 → 账号与安全 → 开启 POP3/IMAP/SMTP → 短信验证 | 免费 | 同上 |
| `SMTP_TO` | 收件人 | 自己填 | — | 默认发给 `SMTP_USER` |

**`SMTP_PASS` 填 QQ 密码会报 `535 Authentication failed`**，必须填授权码。

### 三、目录约定

| 路径 | 要不要自己建 | 说明 |
|---|---|---|
| `.env` | 是 | 从 `.env.example` 复制 |
| `CoreAssets/keywords.json` | **是** | 词库不在仓库里，按 [模板](CoreAssets/keywords.template.md) 自己填 |
| `data/` 下的三个子目录 | 否 | 运行时自动创建 |
| `.edge-cdp/` | 否 | 首次 `launch_edge.py` 自动生成，扫码后写入登录态 |

词库是这个项目的地基。`主体` 为空会导致计划为空、采集 0 条、日报全空——
先跑 `python scripts/plan_queries.py` 看能不能生成查询，是最快的验证方式。

## 模型层（可选）

默认只开两个：**L2 素材理解** 和 **文案评估**。

| 层 | 做什么 | 开关 |
|---|---|---|
| L2 | 整批读一个查询下的 40 条文案，补出规则抽不到的歌名/玩法名 | `layers.material.enabled` |
| 文案评估 | 判断复用短语能不能当二创文案用、怎么用 | `layers.phrase.enabled` |
| L3 噪声复核 | 「证据很多却被判噪声」时报警（平时不触发） | `layers.adjudicate.enabled` |
| L1 查询生成 | 模型召回待验证的查询词 | 未接入流水线 |

模型层只做「补抽」和「复核」，**不做判定**：产出的素材照样走同一套门槛和配额。
任何一层失败都会静默降级，不影响日报发出。

关掉全部模型层也能跑，就是纯规则版——素材卡少几张，没有「可用文案」栏。

## 已知限制

- **只在 Windows + Edge 上验证过**，没有做无头浏览器和其他系统适配。
- **采集覆盖率通常 70~85%**，不是 100%。抖音有软拦截，一个窗口能采 3~9 个查询，
  停一会儿再续采（`--resume`）。
- **抖音网页版不暴露 BGM 字段**，真实配乐靠 SandBase 二次查询，受每日额度限制。
- **评论完全没采**，评论区的梗是盲区。
- **跨圈玩法只抓「挑战/模板」类**，不看纯配乐类和纯文案类的跨圈爆款。
- 词库需要自己维护。主体名单、别名映射会随时间失效。
